Mux Player: preload reverts buffer settings on first play

Reproduction for muxinc/elements#1382, using @mux/mux-player@3.14.1. Both players use preload="metadata". On loadedmetadata, each sets buffer limits through player._hls.config, as the cost optimization guide suggests, and then calls play(). The tables read the config back after playback starts, and the buffered-ahead time 20 seconds later.

      Expected

      In both cases, the values set before play stay in place after play, and the player buffers about 10–15 s ahead. In case A, Mux restores the values saved when hls.js was created (hls.js defaults: 30 s / 60 MB), so the player buffers far beyond 10 s.
